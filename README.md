# SkillSwap
SkillSwap is a website where students can connect to teach and learn skills from each other.

## Features

Our Sprint 1 work focuses on:

- Creating an account and logging in
- Creating and editing a profile
- Adding skills to teach
- Adding skills to learn
- Viewing other users’ profiles
- Matching users based on their skills

## Technologies

- Frontend: HTML, CSS, and JavaScript
- Backend: Node.js and Express
- Database: MySQL
- Version control: Git and GitHub

## Project Structure

- `frontend/` — Website pages, styles, and frontend JavaScript
- `backend/` — Server, API routes, and database connection
- `database/` — Database schema and setup scripts

## Contribution Workflow

1. Create a new task branch from the latest main branch.
2. Implement and test the changes.
3. Push the branch and open a pull request.
4. Have a teammate review the pull request before merging.
5. Record the contribution in the team’s tracking spreadsheet.
6. Keep the merged branch for contribution tracking.
